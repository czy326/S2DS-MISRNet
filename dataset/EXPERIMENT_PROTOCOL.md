# 2×2 交互效应验证协议（先写死，后跑）

数据集：`dataset/` 自建多时相 Sentinel-2 SR 数据集（真实获取日期 + 真实 SCL 云掩膜）。
生成脚本：`collect_s2.py`（采集）→ `build_dataset.py`（成型）。

## 1. 任务定义
给定 T=12 帧真实时相 Sentinel-2 L2A（40 m 等效，48×48），预测目标日期 t\* 的 10 m 影像
（4 波段 B02/B03/B04/B08，patch 192×192）。t\* 永不出现在输入中（无泄漏）。
输入帧**保持有云**（真值日强制晴空率 ≥0.5）⇒ 逐像素云占比是真实的可靠性信号。

## 2. 因子与 arm（MISRNet，`misr/models.py`，约 140k 参数）
| 因子 | 含义 | 实现 |
|---|---|---|
| **F1 = Δt** | 连续时间：逐帧时间距离嵌入 | `dt_mlp(dt/30)` 加到帧特征 |
| **F2 = q** | 观测可靠性：逐像素云端抑制 + 帧晴空率嵌入 | `f *= (1 − sigmoid(γ)·cld)` 且 `f += q_mlp(q)` |

| arm | F1 | F2 |
|---|---|---|
| A | ✗ | ✗ |
| B | ✗ | ✓ |
| C | ✓ | ✗ |
| D | ✓ | ✓ |

## 3. 数据划分（按 AOI 空间不重叠，防泄漏）
train 10 AOI / val 3 AOI / test 5 AOI（见 `build_dataset.py` 的 `SPLITS`）。
test 空间单元 = 5 AOI × 9 patch 位置 = **45**，每单元 10 个目标日 ⇒ 约 450 个样本。

## 4. 训练与评测口径
- 4 个 arm × 2 个种子（2026 / 2027），**等迭代预算**（同一 iter 数，全部 arm 相同），batch 8，AdamW lr 2e-4。
- 损失：**掩膜 L1**（只对目标日晴空像素计入）。
- 评测指标：**逐样本 PSNR**，只在目标日晴空像素上计算（validity mask），4 波段取均值，peak=1（反射率）。
- 评测集：**test 只在最终确认时用一次**；筛选/调参只看 val。

## 5. 判定规则（跑之前写死）
主端点：**交互量** `I = (D − C) − (B − A)`，逐样本配对。

| 判定 | 条件 |
|---|---|
| **通过** | I 点估计 ≥ **+0.10 dB** 且逐样本配对 95% CI 下界 > 0 |
| 部分通过 | 0 < I < +0.10 dB 且 CI 下界 > 0（记录为"方向为正但幅度不足"） |
| 不通过 | CI 含 0，或点估计 ≤ 0 |

辅助端点（同样报配对 CI 与 d_z，不与主端点混谈）：
- F1 主效应：`(C+D)/2 − (A+B)/2`
- F2 主效应：`(B+D)/2 − (A+C)/2`
- 简单效应：`B−A`（无 Δt 时 q）、`D−C`（有 Δt 时 q）、`C−A`、`D−B`
- 联合：`D−A`

统计口径：
1. **逐样本配对** t 检验 + Wilcoxon + d_z + bootstrap/正态近似 95% CI；
2. **空间单元聚合**：先把每个 (AOI, patch) 单元内的 10 个目标日平均，再以 n=45 做配对检验
   （样本间共享输入帧，非独立；这是保守口径）；
3. **两种口径必须同向**才写进结论；
4. **两个种子方向必须一致**；不一致则记为"种子不稳定"；
5. 禁止跨种子比较绝对值（历史经验：arm 绝对 PSNR 跨种子波动可达 1 dB）。

## 6. 必须同时报告的诚实边界
- LR 是 4× 抽稀（COG 概览层，已对齐到基栅格；采集器自带 LR/HR 对齐自检 corr 需 ≥0.99）；日期与云掩膜为真，退化方式为模拟。
- 目标日筛选（晴空率 ≥0.5）会缩小任务难度分布；输入帧的云污染程度决定了 q 因子的可发挥空间。
- 若 q 在**无云污染的子集**上无效而在**高污染子集**上有效，应作为条件化结论报告，不得只报全样本平均。

## 7. 对照基线（不用训练，用于给出可争夺空间）
`bicubic_nearest` / `bicubic_median` / `timeweighted_mean` / `cloudweighted_mean` / `cloudaware_mean`
（见 `bench_baselines.py`）。学习型模型必须至少超过 `cloudaware_mean`。
